Cara pasang (3 langkah)

  1. Muat turun ZIP di atas, kemudian unpack ke mana-mana folder (cth. C:\Tools\FolderLauncher). Perlu Python 3 terpasang.
  2. Double-click fail start.bat — server kecil bermula dan browser terbuka sendiri di http://127.0.0.1:8765.
  3. Tambah folder kegemaran anda, kemudian klik mana-mana kad untuk membukanya. Siap!
ℹ️ Kenapa perlu jalankan secara lokal? Keselamatan browser tidak membenarkan mana-mana website membuka folder PC anda. Server kecil Python ini (tanpa sebarang dependency) yang mengarahkan Windows membuka folder — hanya diakses dari komputer anda sendiri.
🔒 Peribadi: Semua data kekal di PC anda. Senarai folder disimpan dalam paths.json dan tidak pernah dihantar ke mana-mana.
